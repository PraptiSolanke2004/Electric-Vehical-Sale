# 🚗⚡ Electric Vehicle (EV) Sales Analysis – Excel Dashboard

## 📊 Project Overview

This project presents an interactive **Electric Vehicle (EV) Sales Analysis Dashboard** developed using Microsoft Excel. The dashboard converts raw EV sales data into meaningful business insights through data cleaning, Pivot Tables, Pivot Charts, slicers, KPI cards, and interactive visualizations.

The project focuses on analyzing EV sales performance across different **years, states, months, quarters, vehicle categories, and vehicle types** to help identify sales trends and top-performing regions.

## 🔑 Key Features

* 📌 Interactive slicers for **Year, State, and Month**
* 📊 KPI cards for **Total Sales and Average Sales**
* 📅 Quarter-wise sales analysis
* 🚘 Vehicle Category-wise sales distribution
* 🔋 Vehicle Type-wise sales trends
* 🏆 Top 10 state-wise yearly sales comparison
* 📈 Top 5 state-wise sales performance
* 🎨 Clean, interactive, and user-friendly dashboard design
* 🔍 Data-driven insights for better business decision-making
